Bridge is a project that I'm currently working on. At first, the point of this project was to make me more familiar with the java language. Also, it will help me make a better porfolio I believe.

Bridge is a password manager application. To make this application I'm using Java as the main language and JDBC that allows me to interact with my postgresql database which is located on my dedicated server.
My dedicated server runs on Ubuntu Server and it store my database, it has no other fonction other than that for now.

I'm using the package Form from Java to make my GUI and a postgresql Driver to interact with my database.
